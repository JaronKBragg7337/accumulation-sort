The Accumulation Sort

Every repo on the account, run against one question — not whether it's good, but whether it's the thing you actually want.

The criterion. A system qualifies if it (1) runs without you, (2) is changed by having run, and (3) that change is legible when you come back. Continuation plus memory plus consequence. A screensaver passes the first test and fails the other two.

How this is sorted. Tier judgments live in tiers.json and are applied to whatever the API returns today. Each row carries how far verification went: source read means the file tree or source was inspected, README read means the README was, metadata only means description and size alone — those are the likeliest misfiles.

Repos created since the last edit to tiers.json appear under Unsorted rather than being guessed at. Private repos are invisible to the API and are not counted.
